# M2 新材料与内容生成实施计划

> Agent workers: 使用 superpowers:subagent-driven-development 逐任务实施、提交及独立审查。

**Goal:** 新材料经可编辑大纲和章节草稿形成冻结 ContentIR，调用已冻结模板生成全新 Word；真实模型采用与规则回退均有证据。
**依据:** 已批准的 `产品重构方案.md` 第 7/8/9/11/12 节及 `需求.md` V2 当前需求。用户已授权完成 M2，无需再次确认同一设计。
**Architecture:** contracts 定义材料、文档和独立 ContentGenerator；ingest 规范化文本/Markdown，ooxml 读取 DOCX 新材料，pipeline 联接；compose 只构造与验证语义内容；agents 提供可选模型适配器；server 持久化修订、运行快照、事件和产物。
**Stack:** Python 3.11–3.12、pydantic、既有 DOCX/XML、Markdown 成熟解析器、现有可选 OpenAI 客户端与文件事务锁。

## Global Constraints

- 业务只来自新材料或明确用户编辑。模型不接收模板原件、旧正文、旧章名、样式 ID、XML 或布局定义。
- 模型使用独立 ContentGenerator 协议，不能把撰写塞进 DecisionRequest；通过发行入口点发现，组合根注入。
- format_only 零模型请求；organize 超时、关闭、不可达、截断或非法输出有限尝试后规则回退并待确认，保留已编辑/已成功章节。
- 引用须来自当前材料，数字事实须按引用内容核查；引用存在不能宣称语义可靠，最终有用户审核。
- 大纲可增删、排序、改名，正文可逐章修改；模型任务只能基于用户确认的大纲生成，默认不覆盖人工编辑章节。
- 所有可编辑字段持久化；先写完整不可变修订后原子提交指针。冲突409，运行冻结材料/配置/模板具体版本，不在执行时查 latest。
- 取消不得发布迟到结果；并发/重启/独立worker不会重复采用，运行事件和下载可恢复。
- 生成只消费冻结包和 ContentIR，不重新分析模板。server 只经 pipeline，compose/ingest/agents 不导入 ooxml。
- 保留 AGENTS 纪律、类型注解、EngineError、内核零Web/DB、禁用词0、文件≤800行。
- 密钥、真实材料、私有运行记录不入 Git。复用已隔离分支，不合并、不推送，不修改原目录工作内容。
- 本轮不做 M3 新工作台和 M4 Docker/排版视觉验收，不把它们标完成。

## 公共接口

Task1 固定共享契约，之后扩展须同步生产者消费者并记录。模型均继承 FormatModel、extra forbid。

```python
# contracts/materials.py
class ImageExtent(BaseModel):
    cx: int  # 严格正整数 EMU，可信原件几何
    cy: int

class MaterialBlock(FormatModel):
    block_id: str
    kind: Literal['heading', 'para', 'bullets', 'numbered', 'table', 'figure']
    text: str = ''
    level: int | None = None
    items: list[str] = []
    columns: list[str] = []
    rows: list[list[str]] = []
    image_ref: str | None = None
    image_extent: ImageExtent | None = None
    locator: str

class SourceMaterial(FormatModel):
    material_id: str
    name: str
    media_type: Literal['text', 'markdown', 'docx']
    digest: str
    blocks: list[MaterialBlock]
    pending: list[str] = []

# contracts/documents.py
class OutlineSection(FormatModel):
    section_id: str
    title: str
    level: int = 1
    source_refs: list[str] = []  # material_id/block_id

class DraftBlock(FormatModel):
    kind: Literal['para', 'bullets', 'numbered', 'table', 'figure']
    text: str = ''
    items: list[str] = []
    columns: list[str] = []
    rows: list[list[str]] = []
    image_ref: str | None = None
    source_refs: list[str] = []

class SectionDraft(FormatModel):
    section_id: str
    blocks: list[DraftBlock]
    edited: bool = False
    pending: list[str] = []

class DocumentDraft(FormatModel):
    document_id: str
    revision: int
    name: str
    template_id: str
    template_version: int
    material_ids: list[str]
    mode: Literal['format_only', 'organize']
    instructions: str = ''
    outline: list[OutlineSection] = []
    outline_confirmed: bool = False
    sections: list[SectionDraft] = []
    variables: dict[str, str] = {}
    pending: list[str] = []

# contracts/generation.py: bounded requests include only current material blocks
class WritingRequest(FormatModel):
    task: Literal['outline', 'section']
    name: str
    instructions: str
    materials: list[WritingMaterial]  # 语义视图，不含 image_extent 或布局
    outline: list[OutlineSection] = []
    section_id: str | None = None
    capabilities: list[str] = []  # semantic kinds only, never template text/IDs

class WritingResult(FormatModel):
    outline: list[OutlineSection] = []
    section: SectionDraft | None = None
    pending: list[str] = []
    model: str | None = None
    tokens_in: int = 0
    tokens_out: int = 0
    error: str | None = None

class ContentGenerator(Protocol):
    def generate(self, request: WritingRequest) -> WritingResult: ...
```

以上列表默认值实现须用 Field(default_factory=...)，并补类型、长度、唯一ID、行列一致等校验；无来源的人工编辑需显式标 edited，不能伪造已验证来源。GenerationRun 保存 run_id/document_id、kind、state、输入摘要/修订/快照、模型身份、提示版本、调用用量和采用/回退、事件游标、result_revision、产物和安全错误。

最终集成修订：SourceMaterial 保存每个图片实例的可信显示尺寸，DraftBlock 不增加布局字段。WritingRequest 在边界将源材料转为 WritingMaterial/SemanticMaterialBlock，公开模型请求契约与实际请求均不含图片几何。assemble_content 按来源恢复尺寸到 FigureData.image_extent，避免按像素反推后放大。渲染产生的 unresolved 进入运行结果 pending，不发布新草稿修订；大纲相关契约共用 MAX_DOCUMENT_SECTIONS=500，规则生成及提交前均校验总量。
