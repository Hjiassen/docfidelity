# M0/M1 有效模板实施计划

依据：`产品重构方案.md`，已获用户批准执行。范围为模板核心与服务端闭环；M2 内容撰写、M3 工作台、M4 跨环境视觉验收不在本轮完成声明内。

## Global Constraints

- 原件只读，生成只读冻结包，不解析原件、不采集原型、不比较原件。
- 旧业务文字默认全部清空；保留格式与布局不等于保留原文字。固定图片需明确确认。
- 有效包从白名单组装，禁止复制原包再只过滤索引；批注、属性、嵌入文件、旧素材与外链不得进入有效包。
- 分节的首页/奇偶/继承关系需保留；跳过版块必须删除完整节点范围。
- 空原型在入库冻结，保留段落与 run 直接格式；表格行模板来自同表。
- 检测状态与选择独立，未识别默认跳过，人工选择完整范围；不能把未识别称为不存在。
- contracts 仅标准库与 pydantic；registry/render 可依赖 ooxml/platform，server 只调 pipeline。
- 内核错误 EngineError + code；文件不超过 800 行；新增公开函数类型完整。
- 选择影响包摘要，时间不进入内容摘要。V2 存储与旧模板分开。
- 用户可编辑项持久化，冲突 409，冻结版本不可变。密钥与上传材料不入 Git。
- 使用原目录的 Python 环境时以新 worktree src 优先；不回滚原目录修改。

### Task 1: 候选、选择、清理与冻结

归属文件：新增 `contracts/imports.py`，`registry/candidates.py`、`selection.py`、`sanitize.py`、`freeze.py`，按责任拆出 `ooxml` helper；测试 `tests/unit/test_effective_templates.py`、自制 fixture。

公开入口固定为：

```python
def inspect_template(source: Path, *, import_id: str) -> ImportDraft: ...
def default_selection(draft: ImportDraft) -> TemplateSelection: ...
def freeze_template(
    source: Path, selection: TemplateSelection, target_dir: Path, *,
    template_id: str, version: int, name: str,
) -> TemplateVersion: ...
```

契约必须包含源文件摘要、稳定结构节点、候选检测状态、选择范围、变量映射、固定素材、冻结原型与 FormatBindings、清理报告、内容摘要。变量绑定使用冻结节点标记，生成不再识别文字位置。变量 key 验证为标识符；每个变量定位到一个完整文字容器，保留其 run 格式。节点和范围引用服务端验证，越界、重叠、重复绑定返回明确 EngineError。

`effective.docx`、`selection.json`、`contract.json`、`prototypes/`、`cleanup-report.json` 是冻结包格式。包里没有原件；原件由服务端单独存档。契约包含全部供渲染消费的原型位置与插入锚点。加载 sidecar XML 属于消费冻结原型，禁止语义采集。

1. 先写自制 DOCX 测试，在正文、封面、页眉页脚、表格、文本框、批注、属性、图片、嵌入对象放入独立旧内容标记。运行确认新入口缺失导致失败。
2. 实现结构索引、检测状态与默认选择。无封面不默认启用；可人工指定原件节点范围。
3. 按选择重建清理过的白名单包，冻结空标题、正文和表格原型，保留直接格式。外链字段移除；安全页码字段可保留。
4. 实现变量标记、固定图片白名单与支持能力检查。选中不支持对象报错，未选则排除。
5. 测试选择取消、重新冻结摘要变化、原件摘要不变、分节关系、内容残留、直接格式与同表原型。原件为空/损坏必须明确失败。
6. 运行聚焦 pytest、ruff 和新增 contracts/ooxml strict mypy；只提交任务归属文件，提交 `feat(registry): 冻结清理后的有效模板`。

### Task 2: 冻结模板渲染

归属文件：新增 `render/effective.py`、`render/variables.py` 及必要 helper；测试 `tests/unit/test_render_effective.py`。消费 Task 1 的 FormatBindings 与原型字段，禁止修改 registry 的生产实现。

```python
def render_effective(
    bundle_dir: Path, content: ContentIR, variables: Mapping[str, str],
    output: Path,
) -> Path: ...
```

1. 先测试新标题正文采用空原型，旧文字不残留，变量替换保留 run 格式；运行失败。
2. 校验包摘要和版本，打开 effective.docx 的工作副本；变量只按冻结锚点填充。必需变量缺失、未知变量、缺失内容原型不能静默忽略。
3. 使用冻结原型消费标题、段落、列表、表格与图片 IR；复用几何能力，图片与表格只缩不放。同表自己的行模板，列数不匹配明确错误。
4. 测试原件删除后仍能生成、解析器禁用仍能生成、连续三次归一化结果一致；无封面、取消页眉不重加。
5. 聚焦 pytest、ruff、strict mypy；提交 `feat(render): 使用冻结原型生成新文档`。

### Task 3: 导入与不可变版本 API

归属文件：新增 `pipeline/template_imports.py`、`server/template_imports.py`、`server/api/template_imports.py`，接现有应用和依赖；测试 `tests/api/test_template_imports_v2.py`。

HTTP 接口：

```text
POST /api/v2/template-imports (multipart .docx)
GET /api/v2/template-imports/{id}
PUT /api/v2/template-imports/{id}/selection (If-Match)
POST /api/v2/template-imports/{id}/finalize (If-Match + name)
GET /api/v2/templates
GET /api/v2/templates/{id}
GET /api/v2/templates/{id}/versions/{version}
POST /api/v2/templates/{id}/versions/{version}/render (ContentIR + variables)
```

1. 先测试上传、读回、修订保存、重新构建 app 恢复、旧修订 409、冻结与不可变版本；运行失败。
2. `pipeline` 提供候选、验证、冻结、加载与渲染门面；server 不直接 import registry/render/ooxml。
3. V2 namespace 按导入 ID 存原件与已提交草稿快照；每次原子写修订，再提交当前指针。跨线程/进程锁保护修订与 finalize；失败不更新指针，冲突不覆盖他人选择。
4. 冻结先写独立临时包，成功后发布不可变版本和已提交模板引用。重复 finalize 不覆盖旧版本；当前版本详情明确引用 version。
5. 上传复用大小/文件类型/zip 安全验证。路径 ID 验证，原件不通过任意路径对外暴露；render 返回 DOCX 下载。
6. 测试取消版块持久、恶意 zip/path、并发选择冲突、freeze 失败后恢复、渲染下载和 unknown ID。
7. 聚焦 pytest、ruff、OpenAPI 同步；提交 `feat(server): 提供有效模板导入与版本接口`。

### Task 4: M0 纪律、文档与整体验证

控制器执行。更新需求/开发设计/验收/AGENTS 与 ADR 的 V2 生效范围，把领域投影要求标为旧链路。对齐 pipeline 不依赖 agents：共享决策协议/数据归 contracts，适配器由组合根注入，不新增循环依赖。

1. 先增加依赖方向回归检查，确认当前 pipeline import agents 被命中。迁移保持旧公开入口兼容，以现有决策单测证明规则关闭与模型调用留痕不回归。
2. 验证 `pypdfium2` 可用性及许可；不在 M1 引入完整 PDF 预览，不将未执行预览标成通过。
3. 运行 `lint-imports`、三个纪律脚本、`pytest tests/unit -m unit`、API 回归、ruff、strict mypy。新缺陷先加失败回归再修复。
4. 独立审查核心与服务端变更，修复阻断项，再执行对应检查。
5. 启动独立开发服务供 API 试用，明确 M1/M2/M3 边界。不合并、不推送，原工作区与旧服务保留。
