`PASS` 表示该脚本实际检查通过，`FAIL` 为失败，`SUITE` 仅列出未运行用例，`MANUAL` 需要额外环境或人工证据。脚本退出码 0 只表示没有自动失败，**不表示所有验收项已通过**。测试用例与源码扫描各自仅证明覆盖的行为。
